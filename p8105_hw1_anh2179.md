# Problem 2

I created a tibble containing four different variable types: a random
sample of 10 values from a standard Normal distribution, a logical
variable indicating whether each value was greater than zero, a
character variable of length 10, and a factor variable with three
levels. I then used pull() to extract each variable from the tibble and
attempted to calculate its mean.

``` r
problem2_df = tibble( number_vector = rnorm(10), logical_vector = number_vector > 0,
  character_vector = c(
    "a", "b", "c", "d", "e", "f", "g", "h", "i", "j"
  ),
  factor_vector = factor(
    c("low", "medium", "high", "low", "medium","high", "low", "medium", "high", "low"
    )
  )
)
problem2_df
```

The mean worked for the numeric variable, as expected. It also worked
for the logical variable because R treats TRUE as 1 and FALSE as 0 when
performing numerical calculations. As a result, the mean of the logical
variable represents the proportion of observations in the random sample
that are greater than zero. The mean did not work for either the
character or factor variables because these variables contain
categorical rather than directly numeric information.

``` r
mean(pull(problem2_df, number_vector ))
```

``` r
mean(pull(problem2_df, logical_vector))
```

I then applied as.numeric() to the logical, character, and factor
variable in order to determine how R coerces different variable types.
The logical variable was converted to 1s and 0s, which explains why its
mean could be calculated. The character variable could not be
meaningfully converted to numeric values and therefore converted to NA.
The factor variable was able to be converted to integer codes
corresponding to the factor levels. Although these codes are numeric,
they represent categories rather than actual quantitative measurements,
so calculating their mean would not have a meaningful interpretation.

``` r
as.numeric(pull(problem2_df, logical_vector))

as.numeric(pull(problem2_df, character_vector))
```
